tidyclim convert

Convert NOAA GHCN-Daily station files (.dly) into tidy CSV with one row per station, date, and element.

Usage

tidyclim convert USW00023174.dly --elements TMAX,TMIN,PRCP --out la.csv

Options

FlagDefaultMeaning
--elementsallComma-separated GHCN element codes to keep.
--unitsmetricmetric converts tenths of °C and mm; raw keeps file units.
--drop-flaggedoffDrop values with a quality flag other than blank.

Exit codes

0 success, 1 unreadable input, 3 unknown element code.
